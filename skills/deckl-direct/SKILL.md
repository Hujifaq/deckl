# Deckl Direct

Turn the product's identity into a specific visual idea that can guide implementation. Aim for the craft and originality associated with exceptional independent websites; do not promise an award or invent official judging scores.

## Understand

Inspect the user's brief, existing interface, content, brand assets, and available project documentation. Determine whether the surface sells, showcases, informs, or supports daily work. A marketing page and its product dashboard can legitimately need different levels of expression.

Identify the audience, desired action, strongest real asset, and constraints. Preserve existing brand decisions unless a replacement is requested. Infer reasonable details; ask only when competing interpretations would produce materially different outcomes.

If references are supplied, inspect them with available tools. Extract principles such as image scale, type contrast, composition, and pacing. Do not claim to have inspected an inaccessible reference. Do not reproduce another site's identity, proprietary assets, or distinctive arrangement wholesale.

## Develop the concept

Build the direction around something specific to this product: its material, process, place, point of view, or content. "Premium minimal" describes a finish, not a concept.

For example, an architectural practice might organize work around measured volumes and changing daylight. A ceramics studio might use crop, texture, and scale to make the objects tangible. These concepts should lead to different pages even if both use restrained typography.

Select a primary direction. If the user asks for options or the brief has a consequential ambiguity, offer a small set of genuinely different concepts with tradeoffs and a recommendation. Do not produce a large mood-board menu by default.

Define:

- A one-sentence concept grounded in the product.
- Three concrete visual principles, each with an implementation implication.
- Typography roles, palette roles, spacing rhythm, image treatment, and edge/surface treatment.
- The first viewport: message, primary asset, next action, and intended balance.
- A section sequence based on actual content and the visitor's questions.
- One possible signature detail and why this brand earns it; omit it if it competes with the task.
- Touch, small-screen, reduced-motion, and lightweight alternatives for expressive features.

For modern minimal briefs, favor clear hierarchy, deliberate negative space, disciplined type, and strong real imagery. Minimalism removes competing signals; it does not hide useful information or make text tiny. Avoid automatic beige palettes, serif inserts, numbered sections, and ornamental micro-labels when they have no connection to the concept.

## Deliver

Present a compact, actionable direction brief. Separate existing decisions, proposed decisions, and missing assets. State font or asset licensing uncertainty rather than treating paid resources as available.

Keep the result in chat unless the user requests a saved brief or the project already maintains a suitable design document. Update that document only within scope; preserve unrelated decisions. Do not create project files merely to make a concept look complete.

If implementation is also requested, continue it under the established direction without requiring an extra approval gate. This skill can inform implementation, but a direction-only request does not authorize UI edits.

## Quality check

Could this brief describe any company after changing its name? If so, strengthen its product-specific idea. Can a developer derive actual layout, type, asset, and motion decisions from it? If not, replace adjectives with concrete choices. Label concepts as proposals, not verified outcomes.
