# Explore a consequential design choice

Use when the existing direction is rejected or materially different options remain plausible. Skip for a clear brief or a small repair.

Build a small representative slice in an isolated local preview: usually the opening plus one supporting section, with realistic content. Compare a few genuinely different answers to the same brief. Vary focal hierarchy, media relationship, density, or interaction—not merely tint. Each option should be credible on both desktop and mobile.

Name the tradeoff for each: immediate clarity versus discovery, image dominance versus information density, or expressive pacing versus task speed. Keep real assets and factual content consistent so the comparison is meaningful.

If the user requested options, present them before integrating a winner. If implementation is already authorized and no choice is needed, select the strongest fit using the brief, state why, and continue. Preserve the original production surface until integrating the chosen direction; remove temporary exploration files afterward unless requested otherwise.
