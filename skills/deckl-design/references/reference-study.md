# Reference study for an original showcase

Use references to raise the specificity of decisions. There is no single Awwwards layout, and popularity does not make a pattern suitable for every product.

## Find and observe

Start with the user's references. If browsing is available and none were supplied, select two or three relevant examples from [Awwwards' Sites of the Year](https://www.awwwards.com/websites/sites_of_the_year/), then visit the actual sites. Match the subject and available assets, not just the award badge.

The collection includes Lando Norris, Igloo Inc, Opal Tadpole, and Lusion v3. These are discovery leads, not prescribed templates or claims that their live interactions were tested here. Current behavior must be inspected before describing it.

Observe the first viewport, a transition, a content-heavy region, and the ending. Use a browser for scroll behavior; a static screenshot cannot establish timing, pin duration, or responsive behavior. If only screenshots are supplied, use them for composition and propose motion independently.

Write short implementation notes:

| Observation | Translation to this project |
| --- | --- |
| Focal hierarchy and media occupancy | Which real asset deserves that area and what remains visible around it? |
| Typography and line breaks | Which licensed family, width, and wrapping produce the intended reading rhythm? |
| Section transitions and density | Where does this story accelerate, pause, or change scale? |
| Scroll progress and interaction | What changes, why, and what is the static equivalent? |
| Mobile composition | How does ordering or cropping preserve the concept? |

Do not attribute a library, exact font, performance metric, or interaction to a reference without evidence. Do not reproduce proprietary images, branding, copy, or a distinctive arrangement wholesale.

## Turn observations into a concept

Combine useful principles with the project's own subject. A material-focused product can move from silhouette to surface to specification. A cultural event can use poster typography, program rhythm, and expressive color. A studio can introduce a point of view through the work itself. These should yield different sites.

State concrete choices: image occupancy, alignment, hierarchy, reading order, and scene progression. Avoid briefs consisting only of “minimal, premium, modern.” Use a strong static composition as the foundation for the experience.
