# Recognizable generic patterns

These patterns make a site look assembled from defaults rather than designed for its subject. Each one is a finding only when nothing in the brand, content, or task motivates it. None of them proves AI authorship, and any of them can be right in context: say why it fails here before replacing it.

| Pattern | Why it reads as generic | Stronger move |
| --- | --- | --- |
| Every section fades up by the same distance with the same stagger | Motion carries no information and repeats on every scroll | Animate the one relationship that matters in each scene; let the rest simply be present |
| Gradient blob, mesh glow, or noise haze behind the hero | Atmosphere unconnected to the product or its material | Use the real subject: product, work, place, or a color drawn from the brand |
| Frosted-glass cards with white borders over a gradient | Surface effect substitutes for hierarchy | Group with spacing and alignment; keep a surface only around an independent object |
| Icon in a rounded square above three equal feature cards | The same silhouette for unrelated information | Choose a structure from the content: comparison, sequence, demonstration, or a single strong claim |
| Pill badge above the headline ("New", sparkle emoji, version tag) | Ornament competing with the headline | Put real news in the copy, or drop it |
| Logo walls, testimonials, or metrics without a source | Invented social proof misleads visitors | Use supplied evidence only; otherwise leave the space to the product |
| Gradient fill on one headline word | Emphasis by effect rather than by meaning | Use scale, weight, or placement; reserve color for an action or a brand moment |
| Everything centered with identical section padding | No pacing; every section has equal weight | Vary density and alignment by content; let focal moments take more room |
| Bento grid holding unrelated content | Grid shape replaces a reason for grouping | Bento suits equivalent modules; use flow or narrative for everything else |
| Large radius and soft shadow on every surface, cards inside cards | Boundaries compete with content | Keep one surface treatment for independent objects; remove nested containers |
| Abstract 3D renders or stock imagery unrelated to the product | Visitors cannot see what is offered | Real product, work, or people; an honest asset brief when they are missing |
| Single neutral sans at one weight with tiny gray uppercase labels everywhere | Flat hierarchy; secondary text becomes unreadable | Define type roles with real contrast in size and weight; keep metadata readable |
| Cursor followers, magnetic buttons, marquee tickers added for flair | Effects without a concept, often harmful on touch and to focus | Keep an effect only when it develops the site's idea and has a touch and keyboard equivalent |
| Dark theme with a default indigo or violet accent | Palette chosen by habit | Derive accent and ground from the brand and imagery |
| "Unlock the power of…" and similar copy | Says nothing about the product | Describe what it does for whom, using supported facts |

## Using this list

- When designing, check your own output against it before finishing.
- When refining, use it to diagnose, then keep whatever the brand genuinely owns.
- When auditing, cite the location and evidence, and explain the impact on this site; never report a pattern from the list alone.
